# MunizFlix Nativo - download do app de teste

Este repositorio serve **apenas** para baixar o APK de teste do MunizFlix Nativo (`br.com.munizflix.tv`).

- Instala **ao lado** do MunizFlix normal, sem substituir nada.
- **Nao** recebe atualizacao automatica.
- Nao e o app de producao.

## Download

https://github.com/tenmuniz/mf-nativo/releases/latest/download/MFNativo.apk

## O que e

Experiencia de tela nativa em cima do app atual. A navegacao em Android de verdade fica no icone "Nativo (Home)".
